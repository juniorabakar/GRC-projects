# GRC-projects
![banner](https://raw.githubusercontent.com/juniorabakar/GRC-Projects/main/assets/grc_projects_banner.svg)

> Ce repository regroupe mes projets pratiques en Gouvernance, Risques et Conformité (GRC), réalisés de manière autonome en appliquant les connaissances acquises lors de mes formations.
> Chaque projet est construit sur un scénario fictif inspiré de cas réels, avec une documentation complète : méthodologie, livrables et leçons apprises.
---

## Projets

| # | Projet | Statut | Description |
|---|--------|--------|-------------|
| 01 | [SMSI ISO 27001](./01_SMSI_ISO27001/) | `EN COURS` | Implémentation complète d'un SMSI from scratch pour une organisation fictive |
| 02 | [NIST CSF Capstone](./02_NIST_CSF_Capstone/) | `EN COURS` | Programme de cybersécurité complet basé sur le NIST Cybersecurity Framework |
| 03 | [TPRM](./03_TPRM/) | `EN COURS` | Évaluation des risques liés aux tiers : cas d'un fournisseur SaaS fictif |
| 04 | [Incident Response Plan](./04_Incident_Response_Plan/) | `EN COURS` | Plan de réponse à incident pour une organisation fictive |

## Méthodologie

Chaque projet suit la même structure :

```
Contexte          →   Scénario fictif original
Méthodologie      →   Démarche et frameworks appliqués
Livrables         →   Documents produits (évaluations, politiques, plans)
Leçons apprises   →   Ce que je ferais différemment
```
